# Ayush Mishra — Video Editor Portfolio

This is a responsive, static portfolio website for freelance video editor Ayush Mishra.

You can open the website by clicking on the link given,
merry-bienenstitch-31e863.netlify.app

## Upload to GitHub

Upload all files in this folder to the root of your `Personal-Portfolio` repository:

- `index.html`
- `README.md`
- `.gitignore`
- `netlify.toml`
- `_redirects`

The website has no installation or build step. GitHub Pages and Netlify can publish it directly.

## Netlify

After pushing this folder to GitHub, open Netlify, choose **Add new site → Import an existing project**, select the repository, and deploy from the `main` branch.

## Customize before publishing

Replace the placeholder Unsplash images, email address, and social links in `index.html` with your own assets and profiles.
